# Renalith Saga — Tiếng Việt

Bản Việt hóa Renalith Saga v1.02 chạy bằng Ponscripter trên Windows.

## Cài bản vá từ GitHub

Chép thư mục `vietnamese` vào thư mục game gốc v1.02, cùng cấp với các thư mục
`aa`, `at`, `bb`, `ccc`, `image` và `sound`. Giữ nguyên cấu trúc thư mục.
Chạy `vietnamese/Play-Vietnamese.exe`. Bản vá trên GitHub cần dữ liệu game gốc.

## Bản ZIP đầy đủ cục bộ

Giải nén toàn bộ ZIP rồi chạy `vietnamese/Play-Vietnamese.exe`.
Không cần Python, Ollama hay công cụ dịch để chơi.
Save mới nằm trong `vietnamese/saves/saves-vietnamese`.
Bản đóng gói không chứa save cá nhân; hãy giữ bản sao save của bạn khi cập nhật.

## Nội dung

`vietnamese/0.utf` là kịch bản tiếng Việt; `ui` và `ui-images` chứa hình giao diện
đã sửa. Bản dịch có dùng bản nháp bằng mô hình ngôn ngữ và vẫn cần kiểm thử toàn bộ
trò chơi. Các tên riêng có thể được giữ nguyên.

Ponscripter 4.0.0: [mã nguồn](https://github.com/07th-mod/ponscripter-fork/tree/v4.0.0),
giấy phép GPL-2.0 trong `vietnamese/Ponscripter-LICENSE.txt`.
Phông Noto Sans CJK dùng giấy phép SIL OFL trong `vietnamese/Font-LICENSE.txt`.
Quyền đối với game và tài nguyên gốc thuộc chủ sở hữu tương ứng.
